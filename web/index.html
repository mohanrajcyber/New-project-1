Phone boot (real guest)

Termux + QEMU boots our aarch64 AahaOS image from the public repo. Not a random ISO.

  1. Install Termux (F-Droid).
  2. pkg update && pkg install qemu-system-aarch64-headless wget
  3. Download termux-boot-aahaos.sh
  4. Run the command this page builds from your RAM / disk / variant.

Docs: TERMUX.md · images: dist/aarch64

Persist · SSH · share · lock

Live guest needs Termux/QEMU. This page does not run a hypervisor. Persist: guest /data on the AAHA_DISK image (survives reboot). SSH (Net/Lab): ssh -p 2222 root@127.0.0.1 (blank password).
